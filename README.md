# Разработка ИИ-системы прогнозирования задержек и ошибок в данных на участках РЭС «Россети Кубань»

## Описание проекта
Цель проекта — разработать систему машинного обучения для оценки вероятности того, что показания счётчиков по конкретному участку и смене придут с опозданием (более 1 часа) или с ошибкой. Это позволит диспетчерам заранее подстраховаться и снизить количество инцидентов и часов простоя.

## Этап 1: EDA и подготовка данных
На текущем этапе выполнен разведочный анализ данных (EDA) на базе открытого датасета **AI4I 2020 Predictive Maintenance Dataset** (UCI). 

*Важно:* Данный датасет используется исключительно как **учебный стенд** для отработки методики бинарной классификации редких событий и проверки кода. Он не моделирует реальные задержки передачи данных РЭС.

### Ключевые выводы EDA:
* В датасете 10 000 строк и 14 признаков, пропусков и дубликатов нет.
* Целевая переменная (Machine failure) имеет сильный дисбаланс: 3.39% отказов (339 случаев) против 96.61% нормы.
* Выявлена умеренная корреляция целевой переменной с признаками Torque (0.19) и Tool wear (0.11).

## Структура репозитория
* `analysis-rosseti-kuban.docx` — полный текстовый отчёт по Этапу 1 (постановка задачи, выбор данных, результаты EDA, метрики и риски).
* `data/` — папка с исходным датасетом (`ai4i2020.csv`) и графиками, построенными в ходе EDA (6 шт.).
* `notebooks/` — скрипт `eda_ai4i2020.py` с кодом разведочного анализа данных.
* `src/` — папка с базовым скриптом-заглушкой `main.py`.
* `requirements.txt` — список необходимых Python-библиотек для запуска.
